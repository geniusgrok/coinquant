# USDT source receipts and original-session action-space result

2026-10-07; original Coinquant main `f3fe9b8be32fbe8cce324b35c57a06fc929a4958`. Frozen question and single negative-slope macro-entry deferral are in `USDT_FROZEN_GATE.md`. This branch has **no trading-path change**.

`usdt_receipts.py` now collects a fixed, public, no-key 14-day CoinGecko Tether/USD `market_chart` response only on explicit invocation. It appends the original raw response, SHA-256, UTC event date, exact USD market-cap and USDT/USD values, local first receipt/availability time, provisional versus settled-at-receipt stage, data era, revision/same-value predecessor links, and a chained receipt hash. The ledger locks and appends with fsync. `asof` and `signal_at` cannot use a value before that local receipt, cannot substitute a missing daily point, and do not invent a manual start. D+0/D+1 values remain provisional; D+2 is marked settled only after the expected update window. The caller-supplied test path is labeled separately from direct HTTPS capture. No credentials or scheduled collector exist. A direct public 14-day request succeeded; one local private receipt covered 14 daily points. The tool is research-only and does not connect to `coinquant.session` or account state.

The official, free, current 365-day response was fetched once for a clearly labeled `CONDITIONAL_BACKFILL` diagnostic. From its 2025-10 through original 2026-09 endpoint, the frozen negative three-point slope transition yielded **52** unique UTC source dates, **18** dates with an original actual manual start after the vendor's nominal 00:10 time, and **zero** original macro first fills in the covered era. The old public reference CSV, whose pre-2026-04-25 rows used a different intraday-mean downloader and have no original receipt, was used only for the frozen older-era action-space count: **258** conditional event dates, **62** dates with a matching manual start, and **one** overlap with the 20 original macro first fills. Its USDT price control is absent. No private exact start, order or wallet detail is published. The reproducible read-only aggregate is `python -m research.usdt_conditional_screen <current-official-json> <reference-csv> <original-schedule> <verified-first-fills>`; the local originals and raw response stay private.

**Decision:** the one historical overlap is unqualified and cannot establish independence from BTC momentum, volatility or USDT/USD depeg, much less a robust cost-net effect across periods. The recent official backfill has no incumbent macro first-fill action to alter. The frozen source/action gate therefore fails before outcomes: no 795 wallet, funding/fee stress, cost selection, threshold rescue, added short, leverage change, main wiring, Demo or real-account action. The old 150% CAGR / below-50% drawdown reference remains unmet. Future genuine receipts at actual manual starts can be accumulated with the new tool, but they are not retrospective proof; a new decision would need enough first-seen eligible macro entries, controls and missed-winner/cost checks under the unchanged original model.
