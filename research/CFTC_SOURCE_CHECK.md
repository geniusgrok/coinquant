# CFTC TFF CME Bitcoin: narrow source qualification, no trade screen

The searchable old `research/` candidate catalog and archived filenames contained no CFTC/TFF Bitcoin mechanism. This is an independent **CME futures positioning** candidate, not Binance order flow. No directional predicate, threshold, return label or strategy integration was selected.

Only the CFTC's [2024](https://www.cftc.gov/files/dea/history/fut_fin_txt_2024.zip) and [2025](https://www.cftc.gov/files/dea/history/fut_fin_txt_2025.zip) TFF **Futures Only** annual text ZIPs were read; neither ZIP is copied into this branch. The CFTC [historical index](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalCompressed/index.htm) identifies this as the TFF Futures Only family. Its [variable guide](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalViewable/cotvariablestfm.html) names `CFTC_Contract_Market_Code`, `Open_Interest_All`, `Lev_Money_Positions_Long_All`, `Lev_Money_Positions_Short_All` and `FutOnly_or_Combined`. The actual annual files spell their report-date column `Report_Date_as_YYYY-MM-DD`, unlike the guide's `Report_Date_as_MM_DD_YYYY`; a parser must check the file header rather than silently assume the guide's spelling.

Filtering **exact** code `133741` and `FutOnly` yields 53 unique 2024 and 52 unique 2025 report dates, all named `BITCOIN - CHICAGO MERCANTILE EXCHANGE`, contract units `(5 Bitcoins)`, with positive open interest. The proposed dimensionless input would be `(Lev_Money_Positions_Long_All - Lev_Money_Positions_Short_All) / Open_Interest_All`, all three fields in CME contract counts. These annual files establish field meaning and current historical coverage; they do **not** establish the original release time or first published version of each row.

The [current CFTC schedule](https://www.cftc.gov/MarketReports/CommitmentsofTraders/ReleaseSchedule/index.htm) says 3:30 p.m. Eastern, usually Friday for previous Tuesday, but calls its dates *tentative* and lists holiday delays. The [official special-announcement history](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalSpecialAnnouncements/index.htm) proves that this shortcut is unsafe: the September 30, 2025 as-of report was actually scheduled for November 19, not October 3; the October 7 report for November 21, not October 10. The page also records 2025 holiday delay, the 2023 ION backlog/corrections, and revised 2025 catch-up schedules. A 2025 annual row is therefore not a 2025 Tuesday observation available that Friday, and the annual ZIP does not preserve the initial vintage against later correction.

For those **two** separately documented exception dates only, using the next UTC midnight after the announced publication date as a conservative bound, the original manual-start table's first possible sessions are **2025-11-20 18:00 UTC** and **2025-11-22 17:00 UTC**. Naively using the originally intended Friday at 3:30 p.m. Eastern would put **17** and **15** original session starts, respectively, in a window before those report values could have been available. This is an availability check, not a signal or simulated trade. It does not infer the exact intraday release time on an exceptional day or assume a report remained the latest at every later start.

The official pages inspected here do not supply a complete historical first-release and correction chain for every 2020–2026 report. In particular, the 2025 shutdown material has successive catch-up notices; no uniform Tuesday-to-Friday or fourteen-day offset can replace report-by-report evidence. Status: **field and sampled exception qualification only; full historical point-in-time qualification pending; NO_ECONOMIC_SCREEN / NO_ACCOUNT / NO_MAIN_CHANGE**. Any later conditional development study must label unproved dates unavailable and independently freeze an action and control before looking at returns. No other annual archives were downloaded; there was no miner fee fetch, live account, or strategy code change.
