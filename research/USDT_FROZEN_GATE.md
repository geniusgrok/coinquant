# USDT receipt and one-event research gate

Frozen before any Coinquant outcome join, 2026-10-07. Research branch only. Main and all account orders remain unchanged.

**Information thesis:** a contraction in independently received USDT market cap may signal a liquidity headwind for the incumbent DFII10 long when the primary price impulse is absent. Market cap is price × reported circulating supply, not mint amount or exchange deposits. The single unfitted candidate event is the first daily negative sign crossing of a three-point linear slope: `cap[t] < cap[t-2]` while `cap[t-1] >= cap[t-3]`. Four consecutive UTC daily observations are required. No percentile, leverage, short or alternative duration is searched. The event ID is the UTC source date and is counted once. The only possible changed action is **defer an original flat macro `enter` in that actual manual session**, without consuming the macro opportunity; original primary entries, held positions, native protection and next-session evaluation stay under the incumbent model. An event is actionable only if all four versions were actually received by that start and the newest date is the latest completed/available daily date. No event creates a new session or survives beyond its day for this diagnostic. A source outage gives no veto.

First run tests the append-only source path and source-to-manual-clock overlap, not returns. For historical development only, a present-day CoinGecko backfill may estimate how many original irregular manual starts *would* fall after an event. Every such count is labeled `CONDITIONAL_BACKFILL`, never historical PIT. The 2020–2024 original first-seen versions remain missing; the older external project's revised CSV is not used as proof. The source adapter's own future receipts are eligible only at or after actual local receipt time. Official daily points usually become available after ~00:10 UTC, but the ledger never backdates to that expected time. D+0/D+1 cap may revise; later responses append new versions without replacing old ones.

Before looking at an event outcome, compare candidate start count to the original schedule and flat status, deduplicate date and campaign, and measure original BTCUSDT perpetual three-day momentum and completed 20-day return RMS plus USDT/USD deviation from one as controls. If there are enough distinct eligible starts to change an original decision, the only next cheap outcome check is signed seven-day *perpetual* movement at those original starts against comparable nonevent starts, charging the original taker fee and signed funding, while counting the incumbent winners any gate would miss. It is not an executable wallet or new native protection result. Only clear independent net advantage across chronological periods justifies a frozen single-action paired original-wallet comparison with minute execution, protection, continuous drawdown and doubled costs. A missing source clock, no changeable original decision, a proxy result dominated by BTC momentum/volatility or USDT depeg, or no net margin after costs ends the route without a 795 wallet.
