# 经济重建研究协议（2026-09-27 起）

本文件在每一轮正式测量之前登记。机器可读试验清单在 `research/redesign-trials.json`，结果原件在 `evidence/rebuild-20260927/`。

## 固定不变

- 窗口 2020-01-01T00:00:00Z 至 2026-09-20T00:00:00Z（不含），人民币 10,000 元起，中途不加钱。
- 目标：成本后 CAGR ≥ 150%，连续全账户 MDD < 50%（人民币计价；年数 = 秒 / (365.2425 × 86400)）。
- 会话时间表：`research/session_schedule.json`（主序列 795 个会话起点，SHA-256 `f8fb73be…b32a`），每会话 300 秒、每 5 秒一轮、请求延迟 1000 ms。压力序列：旧缺席序列 787、种子随机跳过 20%（638）、种子选定的 21 天空窗（790）。
- 决策链：生产 `coinquant.session.run` → `Lifecycle`，交易所替身为 `research.session_exchange.SessionExchange`，账户状态目录与真实账户隔离。

## 测量器 M1（本轮起的正式口径）

- 成交：IOC 限价 = 卖一 × 1.001；成交量上限 = 请求后 [T+1s, T+2s) 内价格不劣于限价的逐笔成交（Binance vision aggTrades，官方 CHECKSUM 校验）；成交价按限价记。深度代理 = 上一完整分钟成交量；每单取用比例 `BOOK_PARTICIPATION`（生产默认 25%）。
- 同一会话内的加仓：首单未达承诺数量时，后续轮询继续以 IOC 补足；补单前先追加逐仓保证金，使合并仓位的强平价仍在原全仓止损之外。
- 出场：触发单在触发价基础上再劣化 10 bp；只减仓市价单按标记价劣化 5 bp。手续费 0.075%。强平损失逐仓保证金并收 1.25% 清算费。
- 资金费：官方 fundingRate 于 fundingTime 结算；2026-09 无官方月度文件，持仓跨越即视为未知。
- 汇率：FRED DEXCHUS（纽约中午买入价，17:00 UTC 起可用，取不晚于当时的最新值），入金与估值各扣 0.1% 兑换成本；USDT 按美元等值。
- 标记价缺口：分钟缺失时用同分钟成交价区间按全窗口实测最大偏离（下 −2.37%、上 +4.12%）放宽，取不利边界；无成交数据则路径未知，不插值。
- DFII10：ALFRED 时点版本（`research/dfii10_history.py`），与生产 `coinquant.dfii10` 同一可用规则。

## 压力

成本 +50%（手续费 0.1125%）、出场滑点 ×2（20 bp / 10 bp）、深度取用 10%、三条缺席序列。

## 晋升规则

在完整、有效（`known_path` 为真）且 MDD < 50% 的候选中，按人民币终值排名，第一名成为唯一默认，即使低于 150%。

## 轮次

### M0 — 现行默认参照（已完成，旧口径）

SX60+DFII10，单笔 IOC、1% 深度、固定汇率、无出场滑点：¥218,232，CAGR 58.2%，MDD 41.6%（`evidence/rebuild-20260927/R0.json`）。诊断：D1（100% 深度）74.4%；D2（单笔吃 60 秒逐笔，非因果上界）155.0%。结论：主要差距来自执行容量，而非信号。

### M1 — 执行容量改造后的现行默认（本次登记）

试验 F0：现行默认模型 + M1 测量器。F0 的压力与缺席变体同时登记（见 JSON）。

M1 结果（F0，现行默认）：¥2,618,868，CAGR 129.0%，MDD 41.6%，路径已知。压力：成本 +50% → 126.0%；出场滑点 ×2 → 126.5%；深度取用 10% → 126.4%；旧缺席序列与 21 天空窗 → 与 F0 相同（被跳过的会话均空仓无信号）；随机跳过 20% → 83.7%（MDD 41.6%）。

### R1 — 主信号风险倍数（本次登记）

假设：M1 的 MDD 41.6% 留有余量；筛选账户显示主信号风险倍数与 CAGR、MDD 单调同向；宏观风险不起作用（3% 止损风险上限约束）。试验：PRIMARY_RISK = 6.5 / 7 / 7.5，其余与 F0 相同。按晋升规则选择。

R1 结果：p6.5 ¥3,345,175 / 137.5% / MDD 41.6%；p7 ¥3,942,293 / 143.4% / 42.3%；p7.5 ¥3,451,938 / 138.7% / 44.6%（均路径已知）。2023 年起大单受逐笔成交容量限制，风险倍数不再线性放大终值。

### R2 — 会话内补单的请求权重（本次登记）

诊断：2023 年后多数会话首单只成交承诺数量的一小部分（`liquidity_cap`），而持仓轮询里大部分补单被本地请求权重预留（2200/分钟）静默跳过：补单实测约 130（含保证金划转约 210），预留却要求 650。生产修改：补单预留 250、预览 100（实测约 60）；写后若恢复流程已对同一观察对账则不重复对账；手续费率在同一读取器内缓存一分钟（每次 20 权重）。试验：PRIMARY_RISK = 6 / 7 / 7.5。

R2 结果：p6 ¥2,622,732 / 129.1% / 41.6%；p7 ¥4,129,392 / 145.1% / 42.2%；**p7.5 ¥4,998,163 / 152.16% / MDD 44.51%**（IOC 343 笔、零成交 30，路径已知，无强平）。

### R2S — R2-p7.5 压力（本次登记，与 M1 压力相同）

成本 +50% → ¥4,500,628 / 148.3% / 44.8%；出场滑点 ×2 → ¥4,606,097 / 149.1% / 44.9%；深度取用 10% → ¥4,182,480 / 145.6% / 44.5%；旧缺席序列、21 天空窗 → 与主序列相同；随机跳过 20% → ¥1,047,012 / 99.8% / 44.5%。压力下 MDD 全部 < 50%，收益有三项略低于 150%，一项（随机跳过）远低于。

### 晋升

按晋升规则，R2-p7.5 为完整有效候选中终值最高者，`PRIMARY_RISK` 默认改为 7.5。无参数复跑 P1 与 R2-p7.5 终值、MDD、成交逐笔相同。不再继续加大风险倍数：余量只剩 5.5 个百分点 MDD，且不以把回撤压在 50% 以下为目标调参。

### 空头

S1 筛选（`research/short_screen.py`，72 组破位/均线/止损/退出组合，开发 2020–2023 与留出 2024–2026 分别计算）：全窗口最好 +0.8% CAGR，没有任何组合在两段都为正。依“不接入负优势空头”，默认模型（`Campaign.active` 只取方向为正的主信号）仍只开多。账户层和保护层对卖出方向有代码（空头全仓止损止盈替换有单测），但当前默认模型下没有端到端开空路径，这一项需求仍未满足。
