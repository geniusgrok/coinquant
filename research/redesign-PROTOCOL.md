# 经济重建研究协议（2026-09-27 起）

本文件在每一轮正式测量之前登记，按时间顺序追加，后节取代前节；现行口径为最后的测量器 M7 与 M2S 起的所有者缺口决定，下文“M1”“晋升规则”等早期条目保留登记时原文。机器可读试验清单在 `research/redesign-trials.json`。`evidence/rebuild-20260927/` 只保留当前 P7 与 M7 压力原件；M6 原件在 Git 历史 `7c9b2b7`，更早试验原件在 `3e9a696` 及以前。

## 固定不变

- 窗口 2020-01-01T00:00:00Z 至 2026-09-20T00:00:00Z（不含），人民币 10,000 元起，中途不加钱。
- 目标：成本后 CAGR ≥ 150%，连续全账户 MDD < 50%（人民币计价；年数 = 秒 / (365.2425 × 86400)）。
- 会话时间表：`research/session_schedule.json`（主序列 795 个会话起点，SHA-256 `f8fb73be…b32a`），每会话 300 秒、每 5 秒一轮、请求延迟 1000 ms。压力序列：旧缺席序列 787、种子随机跳过 20%（638）、种子选定的 21 天空窗（790）。
- 决策链：生产 `coinquant.session.run` → `Lifecycle`，交易所替身为 `research.session_exchange.SessionExchange`，账户状态目录与真实账户隔离。

## 测量器 M1（本轮起的正式口径）

- 成交：IOC 限价 = 卖一 × 1.001；成交量上限 = 请求后 [T+1s, T+2s) 内价格不劣于限价的逐笔成交（Binance vision aggTrades，官方 CHECKSUM 校验）；成交价按限价记。深度代理 = 上一完整分钟成交量；每单取用比例 `BOOK_PARTICIPATION`（生产默认 25%）。
- 同一会话内的加仓：首单未达承诺数量时，后续轮询继续以 IOC 补足；补单前先追加逐仓保证金，使合并仓位的强平价仍在原全仓止损之外。
- 出场：触发单在触发价基础上再劣化 10 bp；只减仓市价单按标记价劣化 5 bp。手续费 0.075%。强平损失逐仓保证金并收 1.25% 清算费。
- 资金费：官方 fundingRate 于 fundingTime 结算；2026-09 无官方月度文件，持仓跨越即视为未知。
- 汇率：FRED DEXCHUS（纽约中午买入价，17:00 UTC 起可用，取不晚于当时的最新值），入金与估值各扣 0.1% 兑换成本；USDT 按美元等值。
- 标记价缺口：分钟缺失时用同分钟成交价区间按全窗口实测最大偏离（下 −2.37%、上 +4.12%）放宽，取不利边界；无成交数据则路径未知，不插值。
- DFII10：ALFRED 时点版本（`research/dfii10_history.py`），与生产 `coinquant.dfii10` 同一可用规则。

## 压力

成本 +50%（手续费 0.1125%）、出场滑点 ×2（20 bp / 10 bp）、深度取用 10%、三条缺席序列。

## 晋升规则

在完整、有效（`known_path` 为真）且 MDD < 50% 的候选中，按人民币终值排名，第一名成为唯一默认，即使低于 150%。

## 轮次

### M0 — 现行默认参照（已完成，旧口径）

SX60+DFII10，单笔 IOC、1% 深度、固定汇率、无出场滑点：¥218,232，CAGR 58.2%，MDD 41.6%（`evidence/rebuild-20260927/R0.json`）。诊断：D1（100% 深度）74.4%；D2（单笔吃 60 秒逐笔，非因果上界）155.0%。结论：主要差距来自执行容量，而非信号。

### M1 — 执行容量改造后的现行默认（本次登记）

试验 F0：现行默认模型 + M1 测量器。F0 的压力与缺席变体同时登记（见 JSON）。

M1 结果（F0，现行默认）：¥2,618,868，CAGR 129.0%，MDD 41.6%，路径已知。压力：成本 +50% → 126.0%；出场滑点 ×2 → 126.5%；深度取用 10% → 126.4%；旧缺席序列与 21 天空窗 → 与 F0 相同（被跳过的会话均空仓无信号）；随机跳过 20% → 83.7%（MDD 41.6%）。

### R1 — 主信号风险倍数（本次登记）

假设：M1 的 MDD 41.6% 留有余量；筛选账户显示主信号风险倍数与 CAGR、MDD 单调同向；宏观风险不起作用（3% 止损风险上限约束）。试验：PRIMARY_RISK = 6.5 / 7 / 7.5，其余与 F0 相同。按晋升规则选择。

R1 结果：p6.5 ¥3,345,175 / 137.5% / MDD 41.6%；p7 ¥3,942,293 / 143.4% / 42.3%；p7.5 ¥3,451,938 / 138.7% / 44.6%（均路径已知）。2023 年起大单受逐笔成交容量限制，风险倍数不再线性放大终值。

### R2 — 会话内补单的请求权重（本次登记）

诊断：2023 年后多数会话首单只成交承诺数量的一小部分（`liquidity_cap`），而持仓轮询里大部分补单被本地请求权重预留（2200/分钟）静默跳过：补单实测约 130（含保证金划转约 210），预留却要求 650。生产修改：补单预留 250、预览 100（实测约 60）；写后若恢复流程已对同一观察对账则不重复对账；手续费率在同一读取器内缓存一分钟（每次 20 权重）。试验：PRIMARY_RISK = 6 / 7 / 7.5。

R2 结果：p6 ¥2,622,732 / 129.1% / 41.6%；p7 ¥4,129,392 / 145.1% / 42.2%；**p7.5 ¥4,998,163 / 152.16% / MDD 44.51%**（IOC 343 笔、零成交 30，路径已知，无强平）。

### R2S — R2-p7.5 压力（本次登记，与 M1 压力相同）

成本 +50% → ¥4,500,628 / 148.3% / 44.8%；出场滑点 ×2 → ¥4,606,097 / 149.1% / 44.9%；深度取用 10% → ¥4,182,480 / 145.6% / 44.5%；旧缺席序列、21 天空窗 → 与主序列相同；随机跳过 20% → ¥1,047,012 / 99.8% / 44.5%。压力下 MDD 全部 < 50%，收益有三项略低于 150%，一项（随机跳过）远低于。

### 晋升

按晋升规则，R2-p7.5 为完整有效候选中终值最高者，`PRIMARY_RISK` 默认改为 7.5。无参数复跑 P1 与 R2-p7.5 终值、MDD、成交逐笔相同。不再继续加大风险倍数：余量只剩 5.5 个百分点 MDD，且不以把回撤压在 50% 以下为目标调参。

### 空头

S1 筛选（`research/short_screen.py`，72 组破位/均线/止损/退出组合，开发 2020–2023 与留出 2024–2026 分别计算）：全窗口最好 +0.8% CAGR，没有任何组合在两段都为正。依“不接入负优势空头”，默认模型（`Campaign.active` 只取方向为正的主信号）仍只开多。账户层和保护层对卖出方向有代码（空头全仓止损止盈替换有单测），但当前默认模型下没有端到端开空路径，这一项需求仍未满足。

## 测量器 M2（2026-09-28 登记，取代 M1 全部结果）

PR 复核发现 M1 有四处问题，均已复现并修复：

- 补单前未做资金流水审计：`hold` 轮现在先审计，审计失败则本轮不加仓（仍维护保护）；`Lifecycle.may_add` 默认关闭。
- MDD 漏记分钟内有利方向峰值：保守包络先按有利极值（有止盈时以止盈价为上限）更新峰值，再计不利极值。
- 成交时钟：每个写请求在 1000 ms 延迟后生效，期间持仓、保护、资金费照常推进；IOC 按到达后 1 秒内的逐笔成交撮合，回报在该窗口结束时返回。只减仓单到达时若仓位已被保护单平掉则过期。
- 行情时间戳：盘口与标记价按请求时刻之前最后一笔逐笔成交生成，并以该成交时间为时间戳（标记价 = 该成交价 × 上一完整分钟官方标记价/成交价之比）；超过 15 秒无成交则生产新鲜度检查拒绝。
- 标记价缺口：官方标记价、指数价、溢价指数在 2020-01-19 13:09–13:37 均缺 29 分钟。默认口径：缺口首分钟若有仓位，按逐仓上限损失全部逐仓保证金（经原止损单平仓并补足差额）。旧的事后偏离边界仅作敏感性，`path_complete` 为假。

晋升规则不变：在 `path_complete` 为真且 MDD < 50% 的候选中按终值排序。

## 测量器 M3（2026-09-28 登记，取代 M2 结果）

第二次复核指出四处问题，均已复现并修复：

- 宏观覆盖仓补单：整笔持仓（已成交 + 补单）按新价格到止损的损失不得超过入场时 3% 权益额度。
- 追加保证金后重新检查截止时间、停止请求、报价有效期和请求权重；不通过则只保留已追加的保证金，不下单。
- 分钟内事件：持仓期间的有人值守时段按逐笔成交（乘上一完整分钟官方标记/成交比）检查止损、止盈、强平，触发时刻即该笔成交时刻，先于后续资金费和客户端操作；只持有部分分钟时，官方分钟区间无法定序，不利极值计入回撤，可达的止损或强平按不利处理，止盈不假设。
- IOC 成交按每笔匹配成交的时间入账，期间的资金费和保护事件按时间顺序处理；补单途中持仓被止损则余量作废。

参数与 M2S 相同（风险 7.5、缺口偏离边界、同一压力集），不调参。

## 测量器 M4（2026-09-28 登记，取代 M3 结果）

第三次复核指出 M3 新增分钟内处理的两处缺陷，均已复现并修复：

- 逐笔扫描同时按代理标记价记录权益路径：每个新的有利极值先作为峰值，之后的不利极值据此计回撤（止盈价封顶）。
- 补单途中，结算持仓段本身触发止损或强平后，余量立即作废，不再开出无保护仓位。

参数与 M3 相同，不调参。

### M4 结果

P4 与 M3 的 P3 完全一致（终值 ¥5,230,718、CAGR 153.87%、MDD 44.73%，手续费、资金费、逐笔成交列表相同）；六项压力也与 M3 相同。本段历史中没有有人值守时段的逐笔触发，也没有部分分钟不利事件，两处缺陷未影响已记录数字。

## 测量器 M5（2026-09-28 登记，取代 M4 结果）

第四次复核指出：每段逐笔扫描的首笔只更新峰值、不计回撤，同一路径按不同轮询步长推进会得到不同 MDD。修正：逐笔路径有序，每个记录点既更新峰值也按既有峰值计回撤；跳过的点既非新高也非新高后的新低，不影响结果。测试确认 20 秒一次推进与 5 秒四次推进（多空两向）MDD、权益、成交时间完全相同。参数不变。

### M5 结果

P5 及六项压力与 M4 对应账户除试验名外逐字段相同（P5：¥5,230,718、CAGR 153.87%、MDD 44.73%）。

## 测量器 M6（2026-09-28 登记，取代 M5 结果）

第五次复核（F09–F15）与同轮生产修正（F01–F08、F16–F17 及复核外发现）后重测。参数不变，不调参；试验名 P6 与 `M6-*`，压力参数与 M5 相同。

- 资金费顺序：恰好在分钟边界结算的资金费排在该分钟标记价区间与触发之后；分钟内已止损的仓位不付该笔资金费。
- 资金费覆盖：不再用硬编码的 2026-09 起点。`load_base` 要求 2020-01 至 2026-08 每个月度 fundingRate 文件存在，所有时间戳在 8 小时网格 1 秒以内；持仓区间跨过没有官方费率的结算时刻即路径未知。实测覆盖到 2026-08-31T16:00Z，其后 57 个结算时刻（全在 2026-09）未覆盖。
- 空仓估值：空仓期间在每个汇率变化时刻记录人民币权益，汇率造成的回撤计入 MDD。
- 汇率口径改为事后估值：DEXCHUS 观测自观测日 17:00 UTC 起适用；H.10 每周发布，这不是当时可读到的汇率，只用于估值，不进入决策；USDT 按美元等值，兑换成本另计。
- 结果原件记录源码身份（Git HEAD、是否有未提交改动、`coinquant/` 与 `research/` 全部 Python 源码摘要，在试验开始时取）、有效参数、市场文件身份与实际加载的分钟/逐笔文件摘要、资金费流水与每日收盘人民币权益、请求与实际执行的会话数。
- `--limit` 部分运行写入 `/tmp/coinquant-partial`，不覆盖正式结果名；研究旋钮（深度参与比例、主风险）在试验结束或失败后恢复。
- 生产决策链同轮变化：DFII10 只在能改变决定时读取；冷启动在宏观步骤后才结束；未发送或被 Binance 明确拒绝的安全意图（保护、撤单、保证金、只减仓）可在同一身份下再试，入场永远换新周期。

### M6 结果

七份原件都在 `8c22f7c`（无未提交改动）上运行。P6 与 M5 的 P5 终值、手续费、资金费、MDD 逐位相同（¥5,230,718、CAGR 153.87%、MDD 44.73%），六项压力也与 M5 相同。唯一的路径差异：DFII10 在不能改变决定时不再读取，使一笔 IOC 成交的时间与数量、一个会话的轮数不同。本历史中没有“分钟内止损后恰逢边界资金费”的情形，账户也没有在未覆盖的资金费时刻持仓。

## 测量器 M7（2026-09-28 登记，取代 M6 结果）

7c9b2b7 复审（R1–R5）及同轮复审外发现修正后重测。测量规则不变，参数不变，不调参；试验名 P7 与 `M7-*`，压力参数与 M6 相同。只有共用的生产决策链变化：

- 自有 IOC 成交走最短保护路径：复用写后快照，入场预检的合约规则，不再先做完整归属审计；保护与保护失败后的减仓各有保留预算。
- 接管成交须有成交 ID（或无近期游标时的空仓时间边界）证明：此后全部成交属于该入场单且合计等于持仓；外部或人工成交不接管。
- 未知的降风险意图（保护、撤保护、只减仓、保证金）只阻止新风险；在已核实的空仓上、准备 300 秒后仍不可见的，标为 void。
- 保证金历史一行只归属一次转账；空历史不再在 10 分钟后判为失败。
- Binance 文档规定失败的 503（-1008、`Service Unavailable.`、`Internal error; …`）为明确拒绝；签名过期后仍查询不到（-2013）的普通订单为未被接受。

本测量器中读请求零延迟、写请求顺序不变，预期各账户与 M6 相同。

### M7 结果

## 过拟合审计 O1（2026-09-29 登记，在任何 O1 测量之前）

起因：M7 的 P7 收益集中（2020 +1315%、2023 +702%；去掉最好 3 个月 CAGR 降到 69%），2024-01 以后 CAGR 约 65%，滚动一年窗口有 56% 低于 150%；风险倍数与执行修改在同一全窗口上选定，此前登记 11 轮 66 个试验，晋升规则按全窗口终值最高。O1 不重新解释旧结果，只回答：默认参数是不是脆弱的尖点，风险倍数留了多少样本外余量，收益去掉少数月份后还剩多少。

**测量器**：仍为 M7 规则与同一 795 个会话时间表。新增研究旋钮（默认值与生产完全一致）：`impulse_atr`(3)、`atr_bars`(14)、`take_power`(20)、`life_bars`(42)、`retrace`(0.5，止损在脉冲收盘价回撤脉冲幅度的比例)、`dfii_drop`(0.25)、`macro_risk`(3.6)、`primary_risk`(7.5)。区块试验：冻结时间表内落在区块里的会话，全新 ¥10,000 账户，区块结束时估值；不是验收测量，也不写正式结果名。年数按区块日期计。回归检查：默认旋钮的全窗口结果必须与 P7 的终值、MDD 逐位相同。

**候选**（`research/robustness.py`）：基准（全部默认）与 17 个单参数邻居：脉冲倍数 2.5/3.5，ATR 窗口 10/20，持有 28/56 根，止损回撤 0.4/0.6，止盈次幂 10/40，DFII 阈值 0.15/0.35，宏观风险 0.001（等于关闭）/1.8，主信号风险 3.6/5/6。每个候选跑全窗口一次和 2020–2026 七个日历年区块（2026 为 01-01 至 09-20）。共 18 个新试验（全部计入多重比较；此前 66 个）。

**判定规则（先于结果登记）**

1. 划分：A 为开发 2020–2023、检验 2024–2026；B 为开发 2020–2022、检验 2023–2026。开发得分 = 开发区块期末/期初倍数的几何平均。
2. 采纳单参数改动：仅当该改动在 A 与 B 两个划分的开发得分都比基准高至少 10%（几何平均倍数比 ≥ 1.10），且开发区块 MDD 包络都 < 50%。检验区块只用作否决：把被采纳的改动合成一个候选（O1-C）跑同样的全窗口与区块；若 O1-C 在 A、B 两个划分的检验得分有任何一个低于基准，放弃 O1-C，保留基准参数。
3. 风险倍数：在 {3.6, 5, 6, 7.5} 中取开发区块（A 与 B）最差 MDD 包络 ≤ 40% 的最大值（给样本外留 10 个百分点余量）。若 7.5 不满足，默认风险倍数下调到满足者，收益随之降低如实报告。
4. 集中度：报告全窗口分年收益、去掉最好 1/3/5 个月后的 CAGR、滚动 1 年与 2 年年化分布；报告基于周对数收益的去通胀夏普比率（Bailey–López de Prado），试验数 = 66 + 本轮全部候选数。
5. 不移动窗口、不降低目标、不因结果追加候选；额外候选须另起一轮登记。开发/检验划分不是干净的样本外：分区结果在登记前已被研究者见过（此前全窗口选择），因此 O1 只能证伪，不能证明；真正的检验只有此后的前向数据。
6. 最终配置（规则 2、3 的结果）再跑压力：手续费 +50%、退出滑点 ×2、深度参与 10%、随机跳过 20%、缺席序列、21 天空窗，并保留全窗口原件。压力与基准的差距按原样报告。

### O0 — 执行敏感性诊断（2026-09-29 登记，先于结果；O1 之前的回归检查发现）

回归检查（O1 规则 “默认旋钮全窗口结果与 P7 逐位相同”）失败：`883d16a` 复现 P7（¥5,228,630）；`a198f57`、`7839bfb` 为 ¥5,228,803；此后三个生产修复提交（`f34557f` ¥1,695,539、`e715db1` ¥904,076、`eae2285` ¥929,231）都显著更低。12 个会话的探针看不出差别；差别来自本地每分钟请求权重预留：本测量器读请求零延迟，每分钟发出数十次快照，权重接近 2200 上限，任何多出几个读取的修复都让补单预览被 “reserve unavailable” 拒绝，收益因此大幅变化。因此 P7 不再描述 main 的生产代码，且测量对权重上限极度敏感。
