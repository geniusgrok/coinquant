## 收益来自哪里

未加杠杆、未扣成本的每日市场机会指数：BTC累计5.88594x，原通道方向累计6.26504x。这不是可执行账户收益，也不是alpha证明。尤其2023年BTC毛收益155.87%，通道方向仅31.87%；市场机会存在，但方向捕获并不充分。

B1受真实账户约束和保护退出影响，并非现货买入永久持有。它发生一次未细化区间的清算分类；不能隐藏或删去。≤1x是调用时的目标，调用之间敞口会随价格、费用、资金费率和权益变化，最小订单也可阻止细小调整，所以不能假称连续保持1x。

从L17到L21，改变了目标敞口及调用时更新机制，并增加保证金／跳空预留；收益提高不应全部命名为信号alpha。L21没有资金上限拒绝：257次目标执行和145次最小单位／无需调整，剩余调用来自退出或已消耗趋势。不能把资金不足当作其当前主要瓶颈。

L21逐小时比稀疏低9.35个百分点年化，手续费255.77 USDT、高于稀疏164.86。其差异还包括持仓与资金费率路径，不能全部归因于手续费，也不能把频繁调用当作收益上界。

L22的25个趋势持仓全部止损，随后236个稀疏调用被趋势锁定机制阻挡。L24只在新的已完成突破后重新允许进场，减少了这一损失，但仍不及L21。L23则证明不能按单边毛利删空头：L21平仓多头毛利约4,924.79USDT、空头毛亏约467.25USDT，但删空头后2022年账户收益从-8.67%变为-33.11%。这些贡献具有账户路径依赖。

L25检验了慢方向替换而失败；L26用同一通道范围形成连续目标，没有新窗口和杠杆尺度，但稀疏入场增加至73次，回报仍下降。以上结果只排除已测机制，不证明所有同信息策略均无效。

## 实现和验证

- 共用 persistent_hold_replay.py 与 Account，同模型独立运行稀疏／逐小时账户。生产CLI仍默认只读、阻止新风险；没有将研究模型接入实盘。
- L21以20个已完成日收益RMS、7日缺席尺度、2.33倍压力、10%跳空和1%资金费率情景预留计算目标；不使用收益均值和Kelly，也不随止损缩短机械放大。风险尺度20%不是回撤保证；这些预留不是历史最坏界。
- 调用时允许增加／减少，先核验可用资金、全仓保护和强平边界。加仓保留原分配保证金，更新加权入场；实际减仓才按比例释放。逐个增减订单向下取整，禁止为最小订单突破预算。
- 10项相关离线检查通过：多空资金守恒、保证金／保护、资金不足缩量、最小单位、报价方向、波动及通道因果输入和原调度。没有宣称新跑全套本地测试。
- L21两调度的未来扰动六项前缀完全一致；468个共同稀疏时间点的市场状态一致。最终控制运行与L21初始运行七项经济／计数／调度字段一致。后加L26代码只在独立显式reference分支执行，不影响L21路径。
- 发现四份输出的权益gzip截断；结果文件不能代替完整原件。已保留故障原件、补跑受影响路径、验证结果一致。引擎现在关闭并CRC检查临时流后才发布正式trace/result。原因未证实，不宣称是策略错误或某个确定的平台故障。
- L24首次实现误用21日而非既有20日范围，已修正并保存两版：稀疏结果不变，逐小时25.0601%修正为25.2352%。没有用错误版选择窗口。
