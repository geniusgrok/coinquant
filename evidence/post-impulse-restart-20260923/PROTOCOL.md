# PIR1：冲击后首次回撤再启动入场协议

状态：**候选账户回放前冻结**。时间：2026-09-23 UTC。仓库基准：`main` `598c65f17bd9a73c94a03bebecc76f6c9af72083`。截至本文件冻结时，没有生成 PIR1 的账户收益结果。

## 归因依据与可检验缺口

只读重建当前 `impulse_hold` 的 2020-01-01 至 2026-09-20 全窗冲击事件，并按 `research/invocation_draws.json` 的795个冻结调用逐个比对已保存SX60决策、订单及持仓：4小时完成K线信号重建与795/795个已记录regime方向一致。共99个事件（多头55、空头44）；54个多头事件已终止，其中23个在下一个冻结调用前因原止损失效，事后第一个调用仍为空仓且无有效信号，延迟为1至127小时。其余31个多头事件至少被一次调用触达；30个事件有真实入场成交，另一个事件的首个调用先平掉已有仓位，下一次调用才尝试该新机会。55个多头中另有1个在全窗末端仍有效，按右删失处理，不计作漏失。

全795次决策中，680次为空仓且无有效方向，37次只有被SX60多头限制排除的空头机会；30次建立真实入场母单，其他调用记录为持仓、离场或资金处理。不存在`campaign_consumed`拒绝记录。因此，本候选不解除消费限制，也不把`no_signal`直接当成漏赚；只检验：原多头冲击失效后，是否能用已完成价格结构形成一个独立、稀少调用时仍可识别的新入场。

仅作事后诊断的高低价标签：23个“原机会在调用前因止损失效”的事件中，15个之后七日曾有正向最高价移动；中位数约+1.17%，但最低价中位数约-7.77%。这是含未来信息、未扣候选交易成本/资金费/风险且不代表可实现收益的标签，**不参与规则设定、信号筛选或晋级判断**。

## 唯一冻结规则

- **原事件与尺度：**只跟踪现有4小时`impulse_hold`模型产生的多头事件。其触发条件、原止损、中点风险和原7日到期保持原样。令`R = 原触发K线收盘价 - 原止损价`，必须为正；不另选ATR倍数或风险阈值。
- **首次回撤：**从触发事件之后，按连续完成的4小时K线跟踪最高价。用本根K线开始前已完成K线的最高价`peak_before`；第一根满足`peak_before - 本根low >= R`的完成K线是唯一回撤K线，固定其high、low与结束时间，不得改选后续更有利的局部高低点。触发K线本身不作为回撤K线，避免无法识别的同根高低先后顺序。
- **旧事件失效：**按原模型已完成4小时OHLC的止损、止盈或42根K线到期规则失效；若同一根触及多个边界，逐项记录。旧事件失效事实不撤销。子机会的重新启动确认必须发生在失效之后的另一根完成K线上。
- **重新启动：**原事件失效后，第一根4小时收盘价严格高于已冻结回撤K线high时，产生一个子机会。若一个原事件失效后42根4小时K线内未确认，则放弃。只有一个首次回撤、一个确认、一个子机会；不使用未来pivot、未来极值、后续收益标签或逐根回填。
- **新风险锚点：**子机会止损为首次回撤K线low；确认收盘价必须高于止损且止损大于零。安全止盈复用当前远端公式`close * (close / stop) ** 20`，子机会有效期42根4小时K线。止损、止盈和有效期均在确认时确定，之后按当前市场与保护规则处理。
- **优先级与唯一身份：**当前原始`impulse_hold`方向若有效，始终优先；在子机会确认前若出现任一新的原始冲击事件（多或空），取消旧父事件的候选状态，由新原始事件优先。子机会ID为确认K线结束时刻，同时保存原冲击父ID；同一父事件不可重复生成子机会。若账户已有仓位，PIR1仅是入场机会，不会因新子ID强迫同向旧仓离场；原始SX60事件的离场语义不变。仅实际调用时、账户空仓且无优先级更高的原始信号时，可按现有消费/重复调用保护尝试一次。调用后的同次离场不重新入场。
- **账户与执行：**沿用原初始本金、6.0风险尺度、原795/开发468调用、共享账户、共享仓位/资金/精度/容量/保护、五分钟母单与现有成本、资金费、保证金、止损和退出代理。没有第二账户、加本金、提高参与率、延长窗口、附加追踪止盈、修改原机会或参数扫描。

本协议只冻结研究候选，不改变生产`run --execute`阻止、3.6生产默认、资金/凭据或交易所设置。

## 晋级与拒绝

先使用同一当前源码、输入与可用分钟路径运行468次连续开发账户，并与同源码、同配置的SX60配对控制比较。必须同时通过因果/身份、完整账本、资金预算、保护、成交容量和强平硬检查；候选成本后开发终值必须高于配对SX60，MDD必须低于50%，且改善不能由一笔或单一年份独占。否则保留失败记录并拒绝PIR1，不运行全窗。

开发门通过后，仅运行一次同规则、同调用与同资本的795次完整连续账户，与保存并已核验的同输入SX60全窗比较。全窗不优于SX60或连续MDD达到/超过50%即拒绝，不运行压力/缺席矩阵。只有全窗确有净改善且MDD<50%时，才运行冻结联合成本/延迟压力与独立787缺席账户。达到冻结代理150%/50%数值门也不等于历史交易所规则、USDT估值、盘口冲击或生产执行资格通过。

## 已检查的非等价性

- `E/persistent_impulse`延长同一冲击身份且取消日历到期；PIR1等待原机会真实失效，再以新完成结构产生带父子ID、新止损的新子机会。
- D3 V1/V2只改变原事件失效边界/已开仓保护，不产生回撤后的独立入场身份。
- L24 `fresh_breakout`等待现有通道模型的新通道突破；PIR1使用首次回撤K线高点的后续4小时收盘确认，不复用通道突破。
- L8只改已有通道入场后的权益止损风险分配；L13只用受保护campaign利润再投资；二者均不形成新信号。
- T只改原仓保护/跟踪止盈。M60以归一化7/28/84日线收益方向产生campaign；H60依据日线评分延续原冲击事件。均无PIR1的4小时首次回撤/后续收盘确认机制。
