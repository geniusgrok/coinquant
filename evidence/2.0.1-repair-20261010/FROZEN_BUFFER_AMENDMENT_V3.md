# 追加定仓 v3：保留已冻结的强平缓冲

本补充在组合 v2 完整 795 会话及独立审计完成后提出，属于同一历史窗口中的后续缺陷诊断。组合 v2 的原源码、登记、完整回执及 31.1573% CAGR 结果全部保留；不能把 v3 描述成在观察 v2 全期结果之前已登记，也不把本轮结果称为样本外验收。

## 具体反例与根因

组合 v2 出现两笔新增的短持仓：2025-02-09 与 2026-08-20。在同一轮处理内先追加保证金、再追加买入，随后沿已有仅减仓路径退出。它们的原观察并未把退出标为 isolated_margin_cap，不能因持仓短便直接归入第一项保证金比例问题。

按原生形状的记录金额与本次回放的清算公式重建，追加令已冻结的 stop-to-liquidation 绝对距离分别减少约 1.40924 与 4.78678 价格单位；额外约 0.06305110 与 0.70437021 USDT 就能保持原缓冲，且仍满足原有止损压力权益下的 25% 保证金上限。此处缺口金额是根据原件计算的重建值，不能冒充额外的交易所实际观察。

直接调用未改的 _funded_quantity 能按原精度复现两笔实际计划数量和保证金。追加预览按当前 mark 的 10% 重新计算缓冲；持仓恢复却要求保持 position_protection.buffer_distance 中已冻结的实际绝对距离，因此同一笔获准追加的交易会在恢复阶段被判缓冲缩水。

## 最小行为修复

追加定仓接收同一已归属持仓的 buffer_distance，资金测算同时满足原来的当前 mark 10% 缓冲和已冻结距离，采用较严格的距离。首次入场仍按原逻辑建立缓冲。该字段来自既有持久保护记录，不新增策略参数，也不以较小距离覆盖原基线。

25% 保证金上限、10% / 3% 止损预算、既定逆向滑点、实际成本归属、只收紧的浮盈止损、账户状态与锁均保持。既有不满足风险或归属条件的退出继续保留。修复以反例中的几何自洽为依据，不搜索收益参数，不承诺最终 CAGR 必须提高。
