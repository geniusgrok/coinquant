## 一项实质不同的假设及数据资格

只考察**已公开的美国 10 年期通胀保值债券实际收益率意外下行是否在原稀疏调用后提供可成交的 BTC 风险偏好延续**这一独立宏观输入假设。它与已失败的 C7/UC4 风险常数、M60/H60 续持、PIR1 再入场、对称下行空头、现货流/基差和 funding 符号筛选不同。它首先必须以当时可见的 DFII10 数值、首次公开时间（含时区）、每次修订及每次调用的可见版本构建事件；任何止损/仓位定义都必须在看到候选账户前冻结。此处**没有取得满足条件的版本序列，也没有独立成本后可成交事件证据，所以没有冻结交易协议、写策略或试算候选账户**。

实际核查的来源及失败原因：

1. [ALFRED DFII10 版本下载页](https://alfred.stlouisfed.org/series/downloaddata?seid=DFII10) 可按历史 vintage 日期取当时已存在的观测；[FRED observations API](https://fred.stlouisfed.org/docs/api/fred/series_observations.html) 支持 `realtime_start`/`realtime_end` 与历史 `vintage_dates`，而 [vintagedates API](https://fred.stlouisfed.org/docs/api/fred/series_vintagedates.html) 说明其为新值/修订日期。此次查得文档和入口，**没有得到覆盖原 468 次调用的数值版本、逐日首次公开时刻和修订对照**。原生访问 API 的一次只读试取超时；不能推断该数据不存在，也不能把今天的 DFII10 下载值当历史版本。
2. [美国财政部历年真实收益率汇总档](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/daily-treasury-rate-archives) 有 2020–2023 年静态 CSV 链接。它没有给出每个旧观测在各个冻结调用之前的字节版本及修订链；[财政部说明](https://home.treasury.gov/quasi-cubic-hermite-spline-treasury-yield-curve-methodology) 称通常美东 18:00 前提供且可能延迟。因此仅有观察日期或现在的汇总档不足以证明调用前可用。
3. 既存 `../oi-archive-20260923/{REPORT.md,TIME_ELIGIBILITY.json}` 已核验 1,217 对 Binance 官方 OI ZIP/CHECKSUM：开发期前 244 日不存在相应档案，之后 1,140 日完整、68 日缺刻、9 日冲突，下载到的数值历史版本及逐次发布时间未闭合；当前文件修改时间筛查最多 43 次调用（均 2023 年），**不是历史公开数值证明**。没有用 2026 回取值补早期点，也没有再次把 DC10 或 OI 价格组合包装成新净优势。
4. 现有 `../funding-state-20260923/NOTES.md` 的已结算 funding 符号分组、`../spot-flow-20260921/REPORT.md` 及 `../basis-direction-20260921/ECONOMIC_EVIDENCE.md` 是事后归因/无增量证据，既不能作为新的独立机会，也不足以解释约 4.10 倍终值缺口。官方 trade/mark 分钟、已有独立 UC4 事件的全样本净额与 C7 保护风险证据已经检验，不重复改名筛选。
