# 经济重建结果（2026-09-28，测量器 M7）

协议与登记：`research/redesign-PROTOCOL.md`、`research/redesign-trials.json`。本目录只保留当前结果：`P7.json` 与六项压力 `M7-*.json`。M1 结果（含 R2-p7.5 的 152.16% / 44.51%）因 PR 复核发现的测量问题作废；M2 数字（M2-p7.5-bound 153.84% / 44.73%）由 M3 取代，M3、M4、M5、M6 终值相同，M7 低 0.04%（见下文）。更早各轮原件在 Git 历史（M6 原件在 `7c9b2b7`，M5 在 `642d948`，更早的在 `3e9a696` 及以前）。

每份 M7 原件记录源码身份：七份都在 `a6892b3` 上运行，没有未提交改动，`coinquant/` 与 `research/` 的 Python 源码摘要为 `d5e68167…844a`。此后的 Python 改动：`research/rebuild.py` 帮助文本中的示例试验名（P6→P7），以及复审补充修正（保护失败后的减仓只针对证明过的自有成交、续跑计划重读合约规则、纯文本 503 不算明确失败、无准备时刻的旧保证金意图按最后更新时刻界定）。在 `7827f69`（摘要 `4e3d79c3…0244`）上重跑 P7，除源码身份外逐字段与本目录的 `P7.json` 相同；六项压力未重跑。原件还记录有效参数、市场文件与实际加载的分钟/逐笔文件摘要、资金费流水、每日收盘人民币权益，以及请求与实际执行的会话数（全部 `complete=true`）。

## 结论：按账户所有者接受的缺口口径，默认风险 7.5 达到两项目标；压力下收益略低于 150%

2020-01-19 13:09–13:37 UTC，官方标记价、指数价、溢价指数都缺 29 分钟，而账户当时持有多单。要在缺口里触发止损，标记价需比全部成交低 11% 以上；缺口前观测到的最大偏离只有 0.29%。账户所有者于 2026-09-28 决定：这种可能性忽略不计，接受以实测偏离作边界。这是所有者接受的事后边界，不是完整历史路径（`path_complete=false`）。

| 试验（风险 7.5，偏离边界，M7） | 期末 CNY | 成本后 CAGR | 连续 MDD 包络 |

- 基准通过 CAGR ≥150% 与 MDD <50%；所有压力 MDD 均 <50%。
- 成本、滑点、深度三项压力各自让 CAGR 落到 148–149%，余量很薄；随机跳过 20% 会话降到 101%，收益依赖按时表执行几乎每次会话。
- 缺席序列与 21 天空窗结果相同，只说明这两次删除的会话恰好没有改变交易，不代表任意 21 天不运行都安全或收益不变。
- 风险 6/6.5/7/7.5 及执行修改都在同一全历史窗口中比较后选定；M3–M7 的复现不是样本外证明。需要冻结一个候选做前向模拟，记录实际启动频率、机会缺席、成交与预测的差异；不为了通过压力而另选时表。
- 按逐仓可证明上限（缺口首分钟没收全部逐仓保证金），所有风险倍数 MDD 都超过 50%（M2 测量，风险 6：¥821,006，92.7%，75.8%；原件在 Git 历史）。

## M7 修正了什么（7c9b2b7 复审，R1–R5 及同轮发现）

测量规则不变；只有共用的生产决策链变化（登记见 `research/redesign-PROTOCOL.md` 的 M7 节）：自有 IOC 成交有成交 ID 证明时走最短保护路径；接管成交需要同样的证明；未知的降风险意图只阻止新风险，在已核实空仓上作废；保证金历史一行只归属一次划转；文档规定失败的 503 与签名过期后查询不到的普通订单为终态。

登记时预期账户与 M6 相同，实测不同：本测量器的读请求不推进时间，但计入本地每分钟 2200 的请求权重预留。保护路径少读后，M6 因预留不足而跳过的补单预览现在能执行。795 个会话中 28 个不同，23 个只差预览计数，5 个的补单次数与成交不同（首个 2023-10-17，订单 164 提前一轮补单，逐笔上界下成交更大）。MDD 与发生时刻与 P6 逐位相同，终值 ¥5,228,630 比 P6 的 ¥5,230,718 低 0.04%；手续费 32,364 USDT、资金费 43,751 USDT。

## M6 修正了什么（第五次复核，F09–F15）

- 恰好在分钟边界结算的资金费（7,398 个官方结算时间戳中 4,118 个毫秒偏移为 0）排在该分钟的标记价区间与触发之后；分钟内已止损的仓位不再付这笔资金费。
- 资金费覆盖由数据推出：要求 2020-01 至 2026-08 每个月度文件、所有时间戳在 8 小时网格 1 秒内；覆盖到 2026-08-31T16:00Z，其后 57 个结算时刻（全在 2026-09）未覆盖，持仓跨过即路径未知。本历史中账户在未覆盖时刻都空仓（`known_path=true`）。
- 空仓期间在每个汇率变化时刻记录人民币权益。
- 汇率改标为事后估值（见下文）。
- 结果原件绑定源码与输入身份；`--limit` 部分运行不再覆盖正式结果名；研究旋钮在试验后恢复。
- 同轮生产修正（F01–F08 等）进入同一决策链：DFII10 只在能改变决定时读取，因此少了一次读取导致的一轮延迟——P6 的一笔 IOC 成交时间与数量、一个会话的轮数与 P5 不同；终值、手续费、资金费与 MDD 与 P5 逐位相同。

## 测量局限（F20）

- 只有写请求推进 1 秒延迟；串行读请求与 DFII10 历史读取为零延迟。真实网络开销会压缩 300 秒会话、使报价失效并减少补单。读取次数不是墙上的秒数。
- `complete` 只表示选定时间表里的会话都跑完。路径是否已知看 `known_path`，收尾是否核完看每个会话的 `cleanup`。
- 宏观仓的 3% 是价格到止损的预算，不含手续费、滑点和资金费。`capital_limit_usdt` 是下单用的资金规模，不是累计亏损上限。
- 研究账户的维持保证金仍是单档 0.5% 代理；当前预检用观察到的 20 倍档里较保守的维持保证金率。两套口径没有在这次改动后重跑。
- 盘口是上一分钟成交量的单档代理；IOC 成交量取请求到达后 1 秒内价格合格的逐笔成交上界，没有真实对手盘、队列、冲击与主动方向。不是历史 IOC 撮合证明。
- 价格/数量过滤用 2026-09-26 的规则快照，维持保证金是单档 0.5% 代理，不是按日期的档位表；P7 最大名义仓位约 368 万 USDT，历史档位差异不一定可忽略。
- 模拟器接受新增 close-all 保护、平仓后撤另一腿；与真实行为的差异待原生验收（`evidence/bounded-session-20260926/RESULT.md`）。
- 汇率：FRED DEXCHUS 纽约中午买入价，每个观测自观测日 17:00 UTC 起适用。美联储 H.10 每周发布，这是事后估值，不是当时可读到的汇率；它只用于人民币估值，不进入决策。USDT 按美元等值，入金与估值各扣 0.1% 兑换成本，均为假设。

## M5 及更早修正了什么

- M5：每段逐笔扫描的首笔也按既有峰值计回撤；同一路径按不同轮询步长推进，MDD、权益、成交时间相同。
- M4：逐笔扫描记录代理标记价权益路径，止损前的浮盈峰值计入回撤；补单结算持仓段时若触发止损或强平，余量作废。
- M3：宏观覆盖仓补单受入场时 3% 权益止损额度约束；追加保证金后重新检查截止时间、停止请求、报价有效期；有人值守时段逐笔检查触发；IOC 成交按每笔匹配成交的时间入账；复现命令默认缺口口径为 `bound`。
- M2：补单前先做资金流水审计；MDD 包络计入分钟内有利方向的峰值；写请求 1000 ms 后生效；盘口与标记价以请求前最后一笔成交生成。

## 仍未完成

- 开空能力：默认模型只取方向为正的主信号（`Campaign.active`），宏观也是多头；账户与保护层的卖出方向有代码和单测，但默认模型没有端到端开空路径。当前版本按明确的只做多范围验证；若要自动开空，需要一条经冻结协议验证的规则。它不是经济指标的否决项，与经济结果、原生交易资格分别报告。
- 真实账户上的成交、保护替换、断线、迟到成交核对未做。`run --execute` 只在显式试验参数下开放，资格仍是 `NOT_QUALIFIED`。M7 原件的源码是 `a6892b3`；此后的执行改动没有重跑这七份账户。
