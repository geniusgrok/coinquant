# B4 事前协议：多头入场不得追过一个信号风险距离

人话：还是只做多的那次试验。如果打开程序时，价格已经比信号价多走了一个止损那么远，就不再追，也不把这笔机会记成用过。距离事先定死，看到结果以后不放宽、不收紧。

写在 B4 收益之前。B3 的多头账户已知路径成立，终值高于打印对照，收盘 MDD 低于 50%，但 CAGR 仍是 `47.710501527122395%`。稀疏会话可以在冲击柱之后才下单。数量按波动定，不按止损距离缩小，所以价格走远以后，同样的分数对应更大的不利空间。

## 改动

研究状态同时设置 `research_side=long` 和 `research_chase_bound=true`。生产状态两个键都不写。

入场限价使用该机会自己的已完成四小时收盘 `C` 和它自己的止损。风险距离 `R = |C - stop|`。多头只在限价 `<= C + R` 时发送。越过边界不消费机会，下一次新鲜轮询仍可在边界内入场。不把 `R` 改成别的倍数。信号、尺度 3.6、止损、止盈、到期、打印和 795 场日程与 B3 相同。

## 判定

对照是 B3 多头账户：人民币终值 `137481.7850058945982282948216`、CAGR `47.710501527122395%`、收盘 MDD `0.2925892499502880322507127127`。

若连续收盘 MDD 达到或超过 50%，停止这条边界。若人民币终值不高于 B3，这条边界没有增量，不改成更宽或更窄的距离。原生资格保持 `NOT_QUALIFIED`。缺席 787 场不跑。生产默认不变。
