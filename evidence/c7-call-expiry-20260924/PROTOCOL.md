# C7 冻结协议（经济运行前）

研究候选：在 468 个原开发调用上，以 UC4 方向、原单次 campaign 消费规则，复用 SX60 的 6.0 风险尺度、CapitalBudget、五分钟分片入场与计划退出。相同资金、费用、GAP、数量、流动性、funding、SL/TP 与连续高水位。仅新增：持仓所属首笔母单调用满七天时，在**下一次原冻结调用**发起已有 PlannedExit；原方向失效与资金保护可更早退出。没有冻结调用时，只有先前已设置的原生 SL/TP 能触发退出；不虚构定时客户端平仓。计划退出剩余量及后续再入场保持共享执行器原规则。

这与 UC4 6.0 的长期通道续持不同；与 PF55、RR 既有预算控制不同；与 H60/HR60 的 SX60 续持及 M60 的不同信号也不同。可能缩短错误方向的 funding 和风险占用，也可能损失长趋势赢家。独立机会实验证明 163 闭合、2 几何拒绝，UC4 143 笔闭合净额合计正值但多数为亏损；这不足以预测连续账户的最终收益。

以同版数据和执行器配对 SX60 与 C7，先要求完整 468 开发账户 CAGR ≥150%、连续保守 MDD <50%、账本和资金/GAP硬检查通过，才运行冻结的 795 正式全窗及原压力/缺席验收。若有仓保护小时缺失，明确报日期，补齐两类官方 1m 及 .CHECKSUM 后从起点重跑；失败前缀若已经严格越过回撤硬门，可提前经济拒绝，不能推断未完成 CAGR。此处的七天是决策阈值，实际退出可晚于七天；不宣称严格七日清仓能力。
